Shape rules S1–S7异形屏规则（v1.4 新增）

S1屏形判定：从图纸看几面、朝向，AI 先猜（平面 / L / U / 弧形 / 立方体 / 自定义），人确认Shape detection: from the drawings count faces and orientation; AI guesses (flat / L / U / curved / cube / custom), a person confirms S2分面输入：每面尺寸、朝向、维护方式，以及信号输入点和电源输入点Per-face input: size, orientation and maintenance access for each face, plus signal and power entry points S3按面计算：F2 尺寸吸附、F5–F12 回路 / 配电箱 / 数据线按面算；同型号备品按整屏合计Per face: F2 size snapping, F5–F12 circuits / DB box / data cables per face; spares of the same model totaled across the whole screen S4转角：相邻面点间距必须一致（否则阻断）；内角要确认哪面压哪面、净宽怎么扣；外转角要选转角箱体或 45° 切角模组，两面按外边尺寸算，转角处像素要连续Corners: adjacent walls must have the same pixel pitch (otherwise blocked); inside corners need confirmation of which wall overlaps which and how net width is deducted; outside corners need corner cabinets or 45° bevel modules, both walls calculated by outer dimensions, pixels must be continuous at the corner S5画布与处理器：U 形横向展开、L 形（墙 + 地面）纵向展开；每面 1 路输出，单路不超过处理器上限Canvas and processor: U-shape unfolds horizontally, L-shape (wall + floor) vertically; 1 output per face, each within the processor limit S6特殊面：地面面要 GOB 防护和承重；顶面要吊挂和重量；有模型或展品压在屏上要列出Special faces: floor face needs GOB protection and load bearing; ceiling face needs hanging and weight; list any models or exhibits resting on the screen S7资料一致性：同一尺寸在不同资料里不一样时，进确认关，选定前不能计算Document consistency: when the same dimension differs across documents, it goes to the confirmation gate and can't be calculated until one is chosen
