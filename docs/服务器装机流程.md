# AV Proposal Platform · 服务器安装（Windows 安装包，给 IT）

> 装在 **Project Platform 那台服务器（192.168.1.241）** 上，端口 **8081**（3000 / 8080 已被 Project Platform 占用）。同事的电脑不用装任何东西，用浏览器打开 http://192.168.1.241:8081 即可。
> 整套约 10 分钟。卡在哪一步，把那一步的截图发给 Jimmy。
> 每次发布前，安装包都会在 GitHub 的 Windows Server 2022 机器上自动走一遍：首次安装 → 上传样本并读取 → 更新 → 卸载。

---

## 阶段 0 · 装机前确认

- [ ] 服务器是 64 位的 Windows 10 / Windows Server 2016 或更新版本。
- [ ] 决定资料目录和容量（清单 A9），例：`D:\avp-data`，200 GB。数据库、客户原件、生成的文件都放这里。**必须是本机磁盘，不能是网络盘。**
- [ ] 端口 8081 没被占用：命令行执行 `netstat -ano | findstr :8081`，没有输出才对。
- [ ] 用管理员账号登录服务器。

---

## 阶段 1 · 拿到安装包

- [ ] **Jimmy**：在 GitHub 的 [Releases 页面](https://github.com/JimmyLi09/AV-Proposal-Platform/releases/latest)（私有仓库，要先登录）下载 `AVProposalPlatform-Setup-x.y.z.exe`，用 U 盘或共享盘交给 IT。
- 服务器上**不需要**装 Python、Node.js、Git，也不需要 GitHub 密钥。

## 阶段 2 · 安装

1. [ ] 右键安装包 →「以管理员身份运行」。
2. [ ] 如果出现「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。（安装包没有付费的数字签名，所以会有这个提示。）
3. [ ] 程序目录：用默认的 `C:\Program Files\AV Proposal Platform`。
4. [ ] **Data folder 资料目录**：填阶段 0 定的目录。
5. [ ] **「允许公司内网其他电脑访问」保持勾选**：只放行 Domain 和 Private 网络，不放行 Public。
6. [ ] 点「Install」，完成后可以直接打开平台。

安装程序会自动做这几件事：

- 安装 Visual C++ 运行库（文字识别组件要用）；
- 注册 Windows 服务 `avp`（显示名 AV Proposal Platform），开机自动启动，出错 10 秒后自动重启；
- 添加防火墙规则「AV Proposal Platform 8081」；
- 在开始菜单添加「Open AV Proposal Platform」。

静默安装（可选）：`AVProposalPlatform-Setup-x.y.z.exe /VERYSILENT /DATADIR=D:\avp-data`

> 如果之前已经按旧流程（源码 + pm2）装过：先执行 `pm2 delete avp`、`pm2 save`，再运行安装包，资料目录选原来那个，数据会保留。`d:\av-proposal-platform` 文件夹之后可以删掉，注意别删资料目录。

## 阶段 3 · 交付前验收核对表

- [ ] 服务器本机打开 http://localhost:8081，能看到「Choose your name 选择名字」页面。刚装好或刚重启时，等 10–20 秒再刷新。
- [ ] 另一台电脑打开 http://192.168.1.241:8081，也能看到这个页面。
- [ ] 「服务」（`services.msc`）里 AV Proposal Platform 是「正在运行」，启动类型是「自动」；Project Platform 也仍然正常（`pm2 status` 里 `audax` 是 `online`）。
- [ ] 重启服务器后不做任何手动操作，两个系统都能自动恢复访问。
- [ ] 随便建一个项目、上传一张照片，几秒后项目页显示「Read 已读取」或「Attached 已附加」，说明文字识别组件正常。
- [ ] 资料目录里出现 `avp.db` 和 `files` 文件夹。

全部打勾 → 通知 Jimmy 开始试用（试用清单见 `docs/试用清单.md`）。

## 备份（试用期）

- 资料目录（例 `D:\avp-data`）就是全部数据：`avp.db`（数据库）、`files`（客户原件）、`derived`（截图、标注副本等）。
- 试用期都是测试数据，暂不设自动备份。**正式使用前**，IT 按清单 A10 定备份位置和频率。
- 手动备份（管理员 PowerShell）：`Stop-Service avp` → 复制整个资料目录 → `Start-Service avp`。服务在运行时直接复制数据库，可能会复制到一半的状态，所以要先停服务。

## 日常维护

| 场景 | 操作 |
| --- | --- |
| 更新到新版本 | 下载新版安装包，以管理员身份运行，一路「Next」。服务会自动停止、更新、再启动；资料目录和设置都保留，数据库结构在启动时自动升级 |
| 看运行状态 | `services.msc` 里的 AV Proposal Platform，或 PowerShell 执行 `Get-Service avp` |
| 看日志 | `C:\Program Files\AV Proposal Platform\logs\`（程序输出在 `.err.log` 里） |
| 手动重启 | 管理员 PowerShell：`Restart-Service avp` |
| 改服务器设置 | 编辑 `C:\Program Files\AV Proposal Platform\app\config\deploy.local.yaml`，改完执行 `Restart-Service avp` |
| 卸载 | 设置 → 应用 → AV Proposal Platform → 卸载。程序、服务、防火墙规则会删掉，资料目录保留 |

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 同事打不开，本机 localhost 正常 | 安装时没勾「允许公司内网其他电脑访问」：重新运行安装包并勾上。如果勾了还是不行，检查服务器网卡的网络类型是不是被识别成了 Public |
| 运行安装包时提示要装 .NET Framework | 服务程序需要 .NET Framework 4.6.1 或更新（Windows 10 / Server 2016 起自带）。按提示装好后再运行安装包 |
| 服务启动后马上又停了 | 看 `logs\` 里的 `.err.log`。常见原因：8081 被占用，或资料目录没有写入权限 |
| 上传后一直「读取中」，或显示读取失败 | 看 `logs\` 里的 `.err.log`，然后 `Restart-Service avp`，再在项目页点「Re-read 重新读取」 |
| DWG 文件只「附加」不读取 | 正常：要装免费的 ODA File Converter 才能读。装好后在 `deploy.local.yaml` 加一行 `oda_converter: 'C:\Program Files\ODA\…\ODAFileConverter.exe'`，执行 `Restart-Service avp`，再在项目页点「Re-read 重新读取」 |
