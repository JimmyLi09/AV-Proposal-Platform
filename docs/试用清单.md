# AV Proposal Platform · 试用清单（第 1–5 步 + v0.6.0 改动）

> 按顺序走一遍整套流程，每一步对照「应该看到」。和预期不一样的地方，记下 **第几步 + 截图 + 你期望看到什么**，发给我。
> 打开方式：浏览器访问 http://192.168.1.241:8081（用同一个安装包装在自己电脑上试用，就是 http://localhost:8081，装法见 `docs/服务器装机流程.md`）。
> 样本文件：仓库里的 `tests/fixtures/samples/` 有 6 个自制样本，仿照 143-Royal Plaza LED-1，可以先用它们，再换成你们的真实资料。

## 目前用的是示例数据（页面上标黄）

- 产品库：6 款示例产品（IC-25、IC-19、OF-40、SC-4、SC-2、SP-1）。
- 价格：V1 不含价格（CR-6），BOQ 只有数量。
- 规则：v1.3。其中一部分系数是示例值或标着「审核中」，要等清单 C 组定下来。
- 还没做（第 6 步）：导出 PDF / Word / JPG、审核批准、Rev 对比、锁定版本。现在方案总是用最新的规则和产品库计算。
- 试用期间产生的都是测试数据。正式使用前可以整个清空资料目录，从零开始。
- 从 v0.5.0 升级上来的服务器：升级时规则集会自动另存一个去掉 GST 的新版本，所以页头的规则版本号会比下面写的大一号，数字不变。

## 流程

| # | 做什么 | 应该看到 |
| --- | --- | --- |
| 1 | 打开网址 → 添加名字（例 Jimmy · PM）→ 选名字进入 | 不用密码；右上角显示名字 |
| 2 | Projects 项目 → New project 新建项目，项目平台编号先空着 | 列表里该项目显示「Not linked 未关联」 |
| 3 | 进入项目 → 在「项目平台编号」里填编号 → Link 关联 | 编号保存；回到列表显示编号 |
| 4 | 上传 `Lobby_Elevation_RevB.pdf`、`LED_Requirement.xlsx`、`Lobby_site_photo.jpg`、`Concept_render.png` | 先显示「Reading 读取中…」，几秒后：PDF 和 Excel 是 A，照片是 B，效果图是 C「Attached 已附加」；每个文件都标「原件 · 只读」 |
| 5 | 同一个文件再传一次 | 多出一行，旧的那份还在（同名不覆盖） |
| 6 | 新建 LED 方案（例 LED-1 Lobby）→ 点方案名进入 | 显示「Confirm Inputs 确认输入」表 |
| 7 | 点「Fill from files 用文件中的值填入」 | 字段都填上了，并显示来源（文件 · 页 / 单元格）和置信度；「观看距离」来自照片，是 Medium，旁边有「Confirm 确认」按钮；页面提示「还有 1 个字段需要确认」；**这时还没有结果页签** |
| 8 | 点「观看距离」的来源链接 | 下方显示照片里被截出的那一行原文 |
| 9 | 点「Confirm 确认」 | 显示「已确认 · 你的名字」；页面提示屏宽 4500 不是模组整数倍，给出 4480 / 4800 两个选项 |
| 10 | 选 4480 → 「信号源数量」填 1 → Save & calculate 保存并计算 | 状态变成「Calculated 已计算」，出现 5 个页签 |
| 11 | 推荐页签 | 箱体是「Sample IC-25（首选）」，控制器 SC-4，处理器 SP-1；关键数字 35 个箱体、224 块模组、5.73 kW、3 路、5 根数据线；校验：F11 / F14 / F15 通过，另有一条提示「网口全部用满」 |
| 12 | 计算依据页签 → 点任意一行 | 展开显示算式和代入的数值、用到的参数和状态 |
| 13 | 示意图页签 | Level 1：信号源 → 处理器 → 控制器 → LED 屏，配电箱在下方；Level 2：每台设备、每条线缆都标出内部明细第几行 |
| 14 | BOQ 工程量清单页签 | 组标题「LED-1 Lobby」下 7 行：LED 屏 11.47 sqm（带 6 条规格）、Video processor、Sending controller、Server PC set（*Client may provide）、Power distribution and cabling、钢结构 11.47 sqm、运输安装调试 11.47 sqm；页面上没有任何价格 |
| 15 | 把第 5 行数量改成 2 → Save 保存 → 按提示填原因 → 再 Save 保存 | 不填原因保存不了；保存后标「Manual 手动」，旁边显示规则值 1；页面顶部提示「已有 1 项手动修改」。点 Restore 恢复 → Save 保存，回到 1 |
| 16 | 组标题改成「Lobby LED Wall · LED-1」，+ Add line 添加一行 → Save 保存 → Export BOQ Excel 导出 BOQ；再展开「Internal breakdown 内部明细」 | 新行编号 8，标「手动添加」；Excel 和页面同一个格式（No.｜Description｜Qty｜Unit，规格行以「-」开头），第 3 行写 DRAFT · Rev 0 · 规则 / 产品库 / 模板版本；内部明细 13 行，不导出 |
| 17 | 标注页签 → 选照片 → 用「区域」拖一个框 → 用「设置比例」在已知长度的两端各点一下，输入 4480 → 用「设备」点一下，并选明细行「配电箱」→ 保存标注副本 | 区域显示约多少 mm；出现「已另存副本」和下载链接；下载下来的图带编号和图例；项目页原照片没有变化 |
| 18 | Product Library 产品库 → 点 SC-4 → 把带载像素改成 1000000 → 填修改原因 → 另存为产品库 v1.1 | 版本列表多一条 v1.1 |
| 19 | 回到方案 | 页头显示「产品库 v1.1」；推荐页 F11 变成 BLOCK 阻断，并提示有阻断项；示意图里控制器标红 |
| 20 | 产品库里把 SC-4 改回 2300000 → 另存 v1.2 | 方案恢复正常 |
| 21 | Rules Engine 规则引擎 → 把「每路信号线像素」改成 716800 | 试算表里 F9 同时显示 v1.3 的 5 根和「修改后」的 4 根 |
| 22 | 填修改原因 → 另存为 v1.4 → 回到方案 | 页头显示「规则 v1.4」；数据线变成 4 根 |
| 23 | Templates 模板 → 把第 4 行描述改成「Media player PC set」→ 填修改原因 → 另存为模板 v1.1 → 回到方案的 BOQ 页签 | 第 4 行描述变了；页头显示「模板 v1.1」 |
| 24 | 换成你们的真实资料（新建一个项目）再走一遍第 4–17 步 | 重点看认字段准不准、哪些需要改；识别不对的文件请发给我（清单 G1、G2） |
