Pairing rules尺寸配对规则

  • 收集单独成行的「数字 + mm / m」Collect standalone "number + mm / m" entries
  • 横排在框上 / 下 → 屏宽；在框左 / 右或竖排 → 屏高Horizontal text above / below frame → screen width; left / right of frame or vertical text → screen height
  • 同一个数字不会既当屏宽又当屏高The same number won't be used as both screen width and screen height
  • 图片 OCR 给 Low，文字层和 DXF 标注给 MediumImage OCR gives Low, PDF Medium
