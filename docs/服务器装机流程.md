# AV Proposal Platform · 服务器装机流程（Windows，给 IT）

> 装在 **Project Platform 那台服务器（192.168.1.241）** 上，端口 **8081**（3000 / 8080 已被 Project Platform 占用）。
> 按顺序做，每步做完打勾。整套约 30–40 分钟。卡在哪一步，把那一步的报错截图发给 Jimmy。
> 这些步骤在 Linux 上从零演练过一遍；Windows 上用 pm2 启动 Python 的那一步还没在 Windows 上实测过。

---

## 阶段 0 · 装机前确认

- [ ] 服务器能上网（装软件包需要；日常使用只走内网）。
- [ ] 决定资料目录和容量（清单 A9），例：`D:\avp-data`，200 GB。数据库、客户原件、生成的文件都放这里。
- [ ] 端口 8081 没被占用：命令行执行 `netstat -ano | findstr :8081`，没有输出才对。

---

## 阶段 1 · 装基础软件（只需一次）

- [ ] **Python 3.12**：https://www.python.org/downloads/ → 下载 Python 3.12 的 Windows installer (64-bit) → 安装时勾选 **Add python.exe to PATH**。
      验证：`py -3.12 --version` 显示 `Python 3.12.x`。
- [ ] **Node.js**：服务器已经有（Project Platform 在用）。执行 `node -v`：
      - 显示 v20.19 以上或 v22.x：不用动。
      - 更低：到 https://nodejs.org 安装 **22 LTS**（Project Platform 也能正常用）。
- [ ] **Git**：服务器已经有。`git -v` 能显示版本即可。
- [ ] **Microsoft Visual C++ Redistributable（x64）**：文字识别组件需要。多数服务器已经装过；如果之后看到 `DLL load failed`，到微软官网搜 “Visual C++ Redistributable latest” 下载 x64 版安装（免费）。

---

## 阶段 2 · 下载代码（私有仓库，需要只读密钥）

- [ ] **Jimmy 先做**：GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token：
      - Repository access 只选 `AV-Proposal-Platform`；
      - Permissions → Contents：**Read-only**；
      - 生成后把 token 发给 IT（只能读这个仓库，可以随时作废）。
- [ ] 命令行逐行执行：
  ```
  d:
  git clone https://github.com/JimmyLi09/AV-Proposal-Platform.git av-proposal-platform
  ```
  弹出 GitHub 登录窗口时，选用 **Token** 登录，粘贴上面的 token。Windows 会记住它，以后一键更新不再询问。

---

## 阶段 3 · 安装（首次约 5–10 分钟）

- [ ] 逐行执行：
  ```
  cd /d d:\av-proposal-platform
  py -3.12 -m venv .venv
  .venv\Scripts\python -m pip install -r requirements.txt
  cd web
  npm ci
  npm run build
  cd ..
  ```
  `pip install` 会下载文字识别组件（约 100 MB），请耐心等。

---

## 阶段 4 · 服务器设置 + 试跑

- [ ] 在 `d:\av-proposal-platform\app\config\` 下新建文本文件 **`deploy.local.yaml`**（注意扩展名不是 .txt），内容：
  ```
  data_dir: 'D:\avp-data'
  ```
  （路径换成阶段 0 定的资料目录；单引号要保留。这个文件不进 git，以后更新代码不会被覆盖。）
- [ ] 试跑：
  ```
  .venv\Scripts\python -m app
  ```
  本机浏览器打开 **http://localhost:8081**，能看到「Choose your name 选择名字」页面 = 成功。回命令行按 `Ctrl+C` 停掉。

---

## 阶段 5 · 后台常驻 + 开机自启

服务器上已经装了 pm2（Project Platform 在用），直接加一个进程：

- [ ] 执行：
  ```
  cd /d d:\av-proposal-platform
  pm2 start .venv\Scripts\python.exe --name avp --interpreter none --cwd d:\av-proposal-platform -- -m app
  pm2 save
  ```
- [ ] `pm2 status`：`avp` 和 Project Platform 的 `audax` 都是 `online`。

---

## 阶段 6 · 防火墙（只开 Domain 和 Private，不开 Public）

- [ ] 用**管理员身份**打开 PowerShell，执行：
  ```
  New-NetFirewallRule -DisplayName "AV Proposal Platform 8081" -Direction Inbound -Protocol TCP -LocalPort 8081 -Action Allow -Profile Domain,Private
  ```
  （也可以在「Windows Defender 防火墙 → 高级设置 → 入站规则」里手动建：TCP 8081、允许连接、只勾「域」和「专用」。）

---

## 阶段 7 · 备份（试用期）

- 资料目录（例 `D:\avp-data`）就是全部数据：`avp.db`（数据库）、`files`（客户原件）、`derived`（截图、标注副本等）。
- 试用期都是测试数据，暂不设自动备份。**正式使用前** IT 按清单 A10 定备份位置和频率。
- 手动备份：`pm2 stop avp` → 复制整个资料目录 → `pm2 start avp`。（服务在跑的时候直接复制数据库，可能复制到一半的状态，所以先停。）

---

## 阶段 8 · 交付前验收核对表

- [ ] 服务器本机 http://localhost:8081 能打开选名字页面。
- [ ] 另一台电脑 http://192.168.1.241:8081 能打开。
- [ ] `pm2 status` 里 `avp` 是 `online`，`audax`（Project Platform）也仍是 `online`。
- [ ] 重启服务器后不手动操作，两个系统都能自动恢复访问。
- [ ] 随便建一个项目、上传一张照片，几秒后项目页显示「Read 已读取」或「Attached 已附加」（说明文字识别组件正常）。
- [ ] 资料目录里出现 `avp.db` 和 `files` 文件夹。

全部打勾 → 通知 Jimmy 开始试用（试用清单见 `docs/试用清单.md`）。

## 日常维护

| 场景 | 操作 |
| --- | --- |
| 更新到新版本 | 双击 `d:\av-proposal-platform\scripts\update.bat`（拉代码 → 装依赖 → 构建界面 → 重启；数据库结构在启动时自动升级） |
| 看运行状态 / 日志 | `pm2 status` / `pm2 logs avp` |
| 手动重启 | `pm2 restart avp` |

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 同事打不开，本机 localhost 正常 | 防火墙没放行 8081（阶段 6） |
| 上传后一直「读取中」，或显示读取失败 | `pm2 logs avp` 看报错。出现 `DLL load failed` → 装 Visual C++ Redistributable（阶段 1）后执行 `pm2 restart avp` |
| `npm run build` 报 Node 版本太低 | 装 Node 22 LTS 后重新执行阶段 3 的 `npm ci` 和 `npm run build` |
| 更新时 git 要密码或报 403 | token 过期或被作废：Jimmy 重新生成，IT 在「凭据管理器 → Windows 凭据」里删掉 github.com 那条，再执行一次 update.bat 重新输入 |
| DWG 文件只「附加」不读取 | 正常：要装免费的 ODA File Converter 才能读。装好后在 `deploy.local.yaml` 加一行 `oda_converter: 'C:\Program Files\ODA\…\ODAFileConverter.exe'`，`pm2 restart avp`，再在项目页点「Re-read 重新读取」 |
