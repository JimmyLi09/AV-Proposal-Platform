# AV Proposal Platform 平台方案 V1（LED + 投影单面墙）

Oct 14, 2026 · @Jimmy

## 一页概览

V1 是一个售前 Proposal 生成平台，不是报价工具。输入项目信息和客户资料，人工确认后由规则引擎计算，输出设备建议、数量、BOQ、示意图、标注图和 PDF / Word Proposal。首版覆盖两条业务线：**LED** 和**投影单面融合墙**。

| V1 做 | V1 不做（下一版） |
| --- | --- |
| 手工录入 + PDF / Excel / JPG / PNG 资料提取 | DWG 自动出图、DXF 输出、RCP 生成 |
| 人工确认后才进入计算 | 精确施工接线图（Level 3） |
| 可编辑的规则引擎和产品库 | 自动报价、Markup 推算 |
| 每个数字可展开算式与来源 | 多人同时编辑 |
| Cost 人工录入、系统加总 | 完整 B 档（技术深化） |
| 版本管理 Rev 0 / 1 / 2，审核后导出 | 投影多面、弧幕、地面互动、模型投影 |
| PDF / JPG 标注，原件不覆盖 | 其余业务线：BYOD、PA、CCTV、General AV |
| Level 1 概念图 + Level 2 示意图 | 自动修改原 CAD / 3D 文件 |

**已定的约束**

- 不接任何云端大模型。文字识别在本机跑，所有数字由确定性规则算出，模型不碰数量。
- 中央库放公司服务器，只在公司内部使用，不开公网链接。
- 轻账号：选名字登录，不设密码与权限；可以自审自己的 Rev。
- 每台电脑装 Local Agent，可独立运行；服务器断开时只能存草稿。
- 界面中英双语；品牌按 Audax VI，平台名 AV Proposal Platform。
- 先建项目、后补 Project Platform 编号；两套系统只靠编号对应，不共用数据库。
- 保留 Export JPG Boards。

本文档取代「AV Proposal Platform 方案 V1（LED）」。LED 部分内容不变，只是并入了投影。

| F2 模组 | 224 | 宽、高各除以模组尺寸取整后相乘，14 × 16 | 已定 |
| F3 箱体排布 | 35 | 动态规划，28 × 640×480 + 7 × 640×640 | 已定 |
| F4 分辨率 | 1792 × 1024 | 宽、高各除以点间距 | 已定 |
| F5 功率 | 5.73 kW | 面积 × W/㎡（室内 500） | 室内已定，室外 / 租赁示例值 |

| F10 备用模组 | 12 | 模组数 × 5% 向上取整 | 示例值 |

## 投影单面墙规则 P1–P13

顺序是：先定单台画面、算台数，再选镜头、反推机位距离，最后核融合带、清晰度和亮度。定焦镜头不能变焦，画面宽度由距离决定。所以引擎是选镜头、反推机位，而不是给定机位再找镜头。

**两个口径**：投射距离一律从镜头前端量到投影面；V1 只算一排横装。

| 规则 | 算什么 | 算法 | 参数 |
| --- | --- | --- | --- |
| P1 单台画面宽 | w | 墙高 × 长宽比（16:10 为 1.6）；单台时取 max(墙宽, 墙高 × 1.6) | 投影机分辨率 |
| P2 台数 | n | ceil((墙宽 − w) ÷ (w × (1 − 融合下限))) + 1 | 融合下限 15% |
| P3 选镜头 | 镜头 + 机位距离 | 对每款可配镜头算距离 = 投射比 × w；取放得进房间进深的镜头，优先投射比小的（人影少） | 镜头表、可用进深 |
| P4 实际画面宽 | w' | 实际距离 ÷ 投射比（机位被梁、空调等卡住时用实际值） | — |
| P5 融合带 | o | 1 − (墙宽 − w') ÷ ((n − 1) × w')；必须在 15%–30% 之间，否则换镜头或改台数 | 融合范围 |
| P6 画面高覆盖 | 通过 / 不足 | w' ÷ 1.6 ≥ 墙高 | — |
| P7 拼接分辨率 | 横向 px | n × 1920 − (n − 1) × o × 1920 | — |
| P8 像素尺寸 | mm | 墙宽 ÷ 横向 px；最近观看距离低于像素尺寸 × 1 m/mm 时提示「清晰度不够」 | 和 LED 同一口径 |
| P9 单台流明 | lm | 目标亮度 × π × 单台画面面积 ÷ 幕面增益 ÷ derate；选不低于此值的机型 | 目标亮度、derate、增益 |
| P10 剖面遮挡 | 通过 / 提示 | 从镜头到画面底边画光线，在观看位置按 1.8 m 人高检查 | 安装高度、观看区 |
| P11 融合器 | 型号 × 1 | n ≥ 2 必须用；输出路数 ≥ n | 产品库 |
| P12 电源与信号 | 回路、传输方式 | 总功率 ÷ 2.5 kW；信号超过 50 m 改光纤 | 铭牌功率、HDMI 上限待定 |
| P13 内容计量 | 画布、时长、场景数 | 画布 = 横向 px × 1200；时长和场景数由人填，价格人工录 | — |

墙 18325 × 2700 mm，实际用 5 台、国产 0.5 定焦镜头、融合带约 1000 mm。

| 规则 | 规则算出 | 实际 | 结论 |
| --- | --- | --- | --- |
| P1 单台画面宽 | 4.32 m | — | — |
| P2 台数 | 5 | 5 | 一致 |

## 产品库、BOQ 与 Cost

推荐只从产品库里选。产品库每次修改生成新版本，已发出的 Rev 保持当时的版本。Preferred 排在 Approved 前面。

| 业务线 | 产品类别 | 关键字段 |
| --- | --- | --- |
| LED | 箱体 / 模组 | 点间距、模组尺寸、箱体尺寸库、功耗、亮度、防护等级、重量、维护方式 |
| LED | 控制器 / 发送卡 | 带载像素、网口数 |
| LED | 视频处理器 | 输入接口、最大分辨率 |
| 投影 | 投影机 | 流明、分辨率、长宽比、功耗、重量、噪音、可配镜头 |
| 投影 | 镜头 | 投射比（定焦一个值，变焦一个范围）、镜头位移、适配哪几款机器 |
| 投影 | 融合器 / 融合软件 | 输出路数、是否带几何校正 |
| 共用 | 线缆、支架、配件 | 规格、单位 |

镜头单独成为一类产品，而不是投影机的一个属性。公司常用的是国产定焦镜头（0.46 / 0.5 / 0.6 / 0.8），和原装镜头混用，P3 要逐款判断。

**BOQ**：数量来自规则，备注写来源；输入是范围时数量显示为区间。人工增删的行标「手工」。投影的吊架、幕面、涂料、线材都是「视现场」，系统只列出项目、不推数量。

**Cost**：单价人工录入，系统只加总。超过有效期的单价标红；Sell price 人工填，V1 不推 Markup。Cost 不打印到 Proposal；PDF 里显不显示价格，每份 Proposal 自己选。工时也由人填，页面上可以显示参考值：投影安装通常 3 人 2–3 天，融合调试约 1 天。

## 数据对象、Rev 锁定与状态流转

所有对象存在公司服务器的数据库里，原始文件和生成文件存在服务器的资料目录。两条业务线共用一套对象，只是 Extracted Field 的字段名和 Rule 的内容按业务线不同。

| 对象 | 关键字段 |
| --- | --- |
| Project | 项目名、客户、Project Platform 编号（可空）、地点、负责人 |
| Source File | 文件名、类型、A / B / C 分级、存放路径、文件指纹、上传人；只读 |
| Extracted Field | 字段名、值、来源文件、页码、位置、原文截图、置信度、确认人、确认时间 |
| Proposal | 所属项目、业务线（LED / 投影）、档位、当前 Rev、状态 |
| Revision | Rev 号、作者、时间、状态、审核人、锁定内容 |
| Rule | 业务线、编号、版本、算式、参数、结果解释模板、修改原因、修改人 |
| Product | 类别与字段（见上一节）、产品库版本 |
| Cost Entry | 对应产品或项目、分项、金额、币种、录入人、有效期 |
| Annotation | 所属文件、类型（点 / 框 / 图标 / 文字 / 投射锥）、编号、说明、坐标、比例尺 |
| Template | 业务线、章节、标准条款、抬头、版本 |

**每个 Rev 锁定 6 样东西**：确认后的输入、规则版本、产品库版本、Cost 快照、模板版本、生成的文件。锁定后永不重算，要更新就开新 Rev。

| 状态 | 怎么进入 | 能做 | 不能做 |
| --- | --- | --- | --- |
| 草稿 | 新建，或从已批准的 Rev 开新 Rev | 录入、上传 | — |
| 提取中 | 上传完成 | 继续手工录入 | 运行计算 |
| 待确认 | 提取完成 | 改值、逐个确认 | 运行计算 |
| 已计算 | 全部确认后运行规则；或审核退回 | 换型号、录 Cost、标注、改图、导出草稿 | 正式导出 |
| 审核中 | 提交，且没有阻断项 | 通过，或退回并写原因 | 修改 |
| 已批准 | 审核通过（可自审） | 正式导出 PDF、Word、JPG（须联网） | 修改 |

## Proposal 输出

两条业务线用同一套章节骨架，差别只在配置和图。叙述段落由模板按条件拼装，不经任何模型。输出 PDF、可编辑 Word 和 JPG Boards，中英双语，文件属性写入 Rev、规则版本和产品库版本。

| 章节 | LED | 投影单面墙 |
| --- | --- | --- |
| Concept | 屏体位置与用途 | 投影墙位置与内容方向 |
| Recommended Configuration | 尺寸、点间距、分辨率、箱体、功率 | 台数、机型、镜头、机位距离、融合带、拼接分辨率 |
| Quantity Range & BOQ | 箱体、线缆、控制器、备件 | 投影机、镜头、融合器、内容计量 |
| System Diagram（Level 1） | 信号源 → 处理器 → 控制器 → 屏 | 播控电脑 → 融合器 → 投影机 → 墙 |
| Schematic（Level 2） | 设备照片、型号、数量、线缆 | 同左 |
| 专属图 | 箱体拼接与线路图 | 立面融合区图、平面机位图、剖面遮挡图 |
| Annotated Drawings | 客户图纸 / 照片上标屏位、DB Box、机柜 | 客户图纸上标机位、投射锥、融合器位置 |
| Risks & Assumptions | 标准条款 + 缺失字段自动加入 | 同左；另加 4 条「常见坑」和资料齐全度 |
| Calculation Basis（附录） | F1–F16 算式 | P1–P13 算式 |

投影的 4 条固定风险条款来自填写表：融合带可能偏亮、画面清晰度受像素尺寸限制、天花过矮影响安装、天花或建筑抖动可能导致融合错位。

## 部署与运行

服务器和 Local Agent 各管一半：服务器管共享的数据和正式输出，Agent 管本机文件和本机软件。

| 部分 | 运行在 | 负责 |
| --- | --- | --- |
| 中央服务 | 公司服务器 192.168.1.241，端口 8081 | 数据库、规则库、产品库、模板、项目文件、Rev、PDF / Word 生成、界面 |
| Local Agent | 每台电脑（7–8 台），托盘程序，127.0.0.1 | 读本机文件夹、文字与尺寸识别、PDF / JPG 标注、调 AutoCAD 把 DWG 转 DXF、缓存规则与产品库、离线草稿 |
| 界面 | 浏览器打开服务器地址，或双击 Agent | 同一套代码，Agent 自带一份，服务器不在时也能用 |

**离线时**：用缓存的规则继续算、标注、存草稿。不能审核、不能正式导出、不能改规则库和产品库，联网后草稿自动上传。

**安全与网络**：只在公司内网使用，防火墙只开 Domain 和 Private，不开 Public。服务器可以上公网装包和更新，但没有任何一步调用云端模型。

**备份**：中央库丢了，所有 Rev、规则库和产品库会一起丢。备份位置和频率由 IT 在 LED 清单 A10 里定。

**DWG 转换**：装了 AutoCAD 完整版的电脑用它自带的命令行转换；LT 版电脑装免费的 ODA 转换器。

## 开发顺序与验收

先把 LED 全流程跑通（第 1–6 步），再把投影接进同一套框架（第 7–8 步）。第 4 步只依赖样本文件，可以和第 2–3 步同时做。每一步开工前，对应清单里的项要先填好。

1. **数据底座**：数据库、文件存储、轻账号、项目与 Rev 骨架。
   - 先填：LED 清单 A1–A4、A9、A11、B1
   - 验收：能建项目、传文件，原件无法被覆盖
2. **规则引擎框架与 LED 规则**：规则可编辑、带版本，每个结果可展开算式。框架一开始就按「业务线」分，投影接进来时不用改动。
   - 先填：LED 清单 C1、C2、C4、C8–C11、C14
   - 验收：Chuan Grove 等 3 个历史项目试算，对不上的地方逐条记录原因
3. **产品库、设备推荐、BOQ、Cost**。
   - 先填：LED 清单 D1、D2、D7、D8、E1、E2、E5、E6
   - 验收：推荐全部来自产品库；控制器带载不够时会阻断
4. **Local Agent**：文件读取、文字与尺寸识别、确认关、独立运行。
   - 先填：LED 清单 A8、B4、G1、G2、G5
   - 验收：用样本文件跑一遍，识别结果逐份记录；未确认的字段无法进入计算
5. **Diagram 与标注**。
   - 先填：LED 清单 H1–H4
   - 验收：示意图里的每台设备都能在 BOQ 里找到
6. **Proposal 输出、审核、Rev 对比**。到这一步 LED V1 可以上线。
   - 先填：LED 清单 B2、F1–F3
   - 验收：一个真实 LED 项目从上传走到批准导出
7. **投影规则 P1–P13 与投影产品库**。
   - 先填：投影清单 v2 「先做」里的 5 项（114 已闭合，剩目标亮度、derate / utilMin、融合带口径、BHZ611C 参数）；6 款投影机规格书；镜头适配表
