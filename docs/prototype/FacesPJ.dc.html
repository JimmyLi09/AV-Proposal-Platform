New rules多面投影规则 P18–P22（v1.5 新增）

P18屏形与分面：AI 先猜屏形，人确认；每面单独输入宽、高、可用进深、挂高Screen shape and walls: AI guesses the shape first, a person confirms; enter width, height, usable depth and mount height for each wall P19每面独立按 P1–P10 排投影，不跨角投射；投影机在两端角线内均匀排开Lay out projection on each wall independently by P1–P10, never across corners; projectors spaced evenly between the corner lines at both ends P20转角机位冲突：内角两侧第 1 台的距离小于阈值（示例 0.6 m）→ 阻断，人工处理并记录后才能继续Corner mount position conflict: distance between unit 1 on both sides of an inside corner is below the threshold (sample 0.6 m) → blocked; continue only after it is handled manually and recorded P21展开画布：宽 = 各面融合后像素之和，高取各面最大；融合器输出数 ≥ 投影机总数Unfolded canvas: width = sum of blended pixels of all walls, height = max of all walls; blender outputs ≥ total projectors P22弧形幕 / 环幕：必须做几何校正，融合器不支持曲面校正时阻断Curved screen / 360 ring screen: geometric correction required; blocked if the blender does not support curved-surface correction
